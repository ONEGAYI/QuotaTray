# 领域文档消费规则

工程技能在本仓库探索代码前，按以下规则消费领域文档。

## 探索前先读

- 仓库根 `CONTEXT.md`（当前不存在则静默跳过，不提示创建）。
- `docs/adr/`：读与工作区域相关的 ADR（当前不存在同理）。
- **本仓库的词汇基准是 `AGENTS.md` 的「术语表」与「设计决策快照」两节**——
  issue 标题、重构提案、测试命名等输出应使用其中定义的术语，不漂移到
  项目明确避开的同义词（如「历史库」不写成「数据库」）。

## 布局

单一上下文（single-context）：全仓库一个语境，无 `CONTEXT-MAP.md`。
若将来引入 `CONTEXT.md` / `docs/adr/`，按需创建，不预建。

## 与 ADR 冲突时

输出与既有决策记录矛盾时显式标注冲突而不是静默覆盖
（本项目近似的决策记录是 `AGENTS.md` 设计决策快照，冲突时同样显式提出）。
