# 悬停面板：显示目标与列表浏览解耦

裁定 2026-10-22（所有者确认）。

托盘悬停面板默认改为多条目列表（全部启用账户）+ 详情抽屉，设置项可回退单账户。
托盘圆环的显示目标（`tray_icon_entry_id`）不再由「正在查看哪个账户」隐式决定：
列表点击只切换抽屉内容，改显示目标必须经抽屉身份行右侧的 on/off 圆环显式点击
（单选语义——显示目标恒存在，取消没有落点；off 态整环灰）。圆环内文字为 on/off，
圈外弧长与托盘圆环同源；列表里显示目标的头像外套同源进度的圆角矩形环。
单账户模式保留升级前的耦合行为（账户下拉即切换显示目标）。

## Considered Options（未采纳）

- 点行同时切换显示目标（保留旧耦合）：浏览一圈会反复改写持久化设置并重绘托盘图标
- 允许多选/取消显示目标（取消后回退第一个启用条目，标记自己跑位，用户以为操作未生效）
- 抽屉内用普通复选框而非 on/off 环（占用一整行高度，压缩态不可用）
- 列表内拖拽排序（悬停面板是「看」的界面，顺序回主窗口改）
- 每次悬停记忆上次查看的账户（总览价值被单账户路径侵蚀）
- 面板加宽到两列（约 608）常驻列表 + 详情（悬停即弹出接近主窗口宽度的浮层）
