# 主度量与剩余口径

裁定 2026-09-26（所有者确认）。

展示偏好与数据形状解耦：条目级 `primaryMetric`（`auto` / `percent` / `amount`，缺省 `auto`）控制摘要位（主文案、圆环、托盘行体）优先展示的度量形态；指定的度量不可算时静默回退另一度量（逐窗口），试查反馈区 toast（右对齐、带关闭按钮、不自动消失）列出回退窗口，`auto` 恒不警告。百分比口径在展示与提醒层统一翻转为**剩余百分比**（100−已用）：主文案「剩余 N%」、低余额阈值语义「剩余 ≤ 阈值触发」；协议层 `used` 保持**已用百分比**语义不动（模板/脚本填写约定与历史库存量数据零迁移）。存量设置经字段改名迁移自动翻转（读旧字段取 100−旧值写入新名并删除旧字段，幂等且回滚安全），新默认 20。使用统计曲线派生从单选改双产：同一窗口的金额与百分比作为两个独立可选组合项（同智谱多窗口并存机制），百分比曲线维持既有剩余口径。

## Considered Options（未采纳）

- 全局设置级开关（余额型/限额型偏好相反，一处开关无法按条目分治）
- 两级偏好（全局默认+条目覆盖，v1 用不上的配置面）
- `primaryMetric` 二值无 `auto`（缺省与显式选择混同一值，升级行为漂移且不可辨）
- 协议层翻转 `used` 为剩余语义（全部存量模板/脚本/预置 provider 与 30 天历史数据失效）
- 阈值原地翻转+版本标记（回滚版本或拷贝旧 settings 文件会二次翻转，语义颠倒）
- 低余额提醒跟随主度量按金额判断（多币种条目无单一金额阈值可定）
- 主文案双显「剩余 X · 已用 N%」（紧凑位放不下，且未解决偏好选择）
- 曲线按偏好单选度量（正交诉求：统计页要的是「并存被选」，非「跟随摘要位」）
- 主文案优先序全局翻转为剩余金额（方案 A：矛盾只翻了面，仍无选择权）
