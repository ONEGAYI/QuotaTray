已定案的对齐点

  1. 层结构：方案A 单环叠弧——同一根环，满圈弧层层向上叠，16px 下可读性最好，层数再多环不挤细
  2. 颜色规则：多层时全部弧层用预设色循环（绿→蓝→紫→青→粉→靛，绿开头即您的 ¥180 例子）；只有消耗到最后一圈（余额 < 每圈单位）时唯一弧用阈值色
  3. 阈值色输入：填充比例，连续渐变（≥60% 绿、30~60% 黄过渡、<30% 红）
  4. 溢出样式：层数 > 4 → 满环（第 4 层循环色）+ 中心缩写文字
  5. 每圈单位：全局设置，默认 100，设置页可调
  6. 多 provider：托盘单图标默认显示第一个启用条目；右键托盘菜单「图标显示」子菜单可切换，选择持久化
  7. 中心文字：≤4 字符（45% / 180 / 1.2k / 311k）；16px 实际尺寸下偏小，文字以 32px 渲染尽力保证，悬停 tooltip 兜底
