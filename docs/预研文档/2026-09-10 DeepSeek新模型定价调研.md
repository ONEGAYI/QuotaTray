# DeepSeek 新模型定价调研（V4.1-Flash 发布）

> 调研动机：核验 DeepSeek 官网近期模型变动，判断 `data/pricing/v1/catalog.json`（revision 1）的 DeepSeek 数据是否需要更新。
> 数据核对时间：2026-09-10（详见文末）。

## 结论

**需要更新定价目录，且更新核心是模型阵容而非 CNY 价格数字。** DeepSeek 于今日（2026-09-10）正式发布 **V4.1-Flash**（模型名 `deepseek-flash`），官网定价页已同步改版，涉及三方面变动：

1. **新模型**：`deepseek-flash`（DeepSeek-V4.1-Flash，552B MoE 非对称架构、原生视觉理解），今日 12:00（北京时间）起生效降价后的新价。
2. **模型下线**：V4-Flash 与 V4-Flash-Vision-Exp 已下线（官方原话「对应模型已下线」），旧模型名暂时保留兼容路由，请求由 V4.1-Flash 服务并按 Flash 价格计费——catalog 的 `vision` 条目应按项目规则转 `retired`。
3. **预告性下线**：V4 Pro 官宣将于 **2026-09-14 12:00（北京时间）起**路由到 V4.1-Flash 并按 Flash 价格计费，直至未来 V4.1 Pro 上线——`pro` 条目数字虽不变，4 天后实际计费语义改变。

价格数字方面：**CNY 档 flash/pro 的 catalog 现值与今日生效的官网新价一致**（详见「基线疑点」）；**USD 档 flash 需更新**（官方降价）。

### 本次调价的幅度（flash 档，峰值对比旧价）

旧价指 2026-08-16 至 09-10 生效期的价格（CNY peak 0.10/3.0/9.0，USD peak $0.014/$0.44/$1.32；来源见「时间线」）：

- CNY：缓存命中 0.10 → 0.04（约 -60%）；缓存未命中 3.0 → 2.0（约 -33%）；输出 9.0 → 8.0（约 -11%）
- USD：缓存命中 $0.014 → $0.006（约 -57%）；缓存未命中 $0.44 → $0.30（约 -32%）；输出 $1.32 → $1.20（约 -9%）

与官方新闻「More efficient architecture. Lower API prices.」口径一致（<https://api-docs.deepseek.com/news/news260910>）。

### 基线疑点（如实记录）

catalog 的 CNY flash 标注 `verified_at: 2026-09-09`、价格 peak 0.04/2.0/8.0，但 9 月 9 日当天官网实际显示的是**旧价 0.10/3.0/9.0**——本地固化的官网快照 `scripts/fetch_pricing/tests/fixtures/deepseek_zh_2026-09-09.html` 可证。基线数字却与 9 月 10 日才生效的新价一致。该价格的录入来历（提前预填、或核对时使用了过期页面）无法从现有证据确证；不影响本次结论——**以官网今日实抓数据为准，CNY 数字无需改动，模型语义必须改动**。

另一佐证：官方新闻明确「新价格自 2026-09-10 04:00 UTC（北京时间 12:00）生效」，而 exa 渠道今日返回的仍是改版前三列旧价缓存——多渠道时间差恰好印证「今日改版」。

## 四、本地抓取组件影响评估

对象：`scripts/fetch_pricing/providers/deepseek.py` 及其 fixture。结论是**解析器主体无需改动，但有一处必须适配、两处建议更新**。

### 无需改动的部分

- 中文页解析锚点（「模型」首格定位表格、「百万tokens输入（缓存命中/未命中）」「输出」「空闲/高峰时段」「X元」价格格式）在新版两列结构下全部成立。
- 列数从 3 变 2 由既有的「价格格数 = 模型数」校验自适应，这正是当初不依赖 CSS class 的设计意图。
- 「高峰 = 空闲 × 2」自校验对新价依然通过（0.04 = 2×0.02 等）。

### 必须适配：表头脚注上标混入模型 ID

新表头单元格为 `deepseek-flash(1)`、`deepseek-v4-pro(2)`（带脚注引用上标）。现有 `_strip_tags` 只去 HTML 标签，解析出的 `model_id` 会带上 `(1)` 尾巴，产出脏数据。建议在提取表头后清理尾部 `\(\d+\)` 标记。

### 建议更新：USD 通道与 fixture

- **英文页已恢复**：组件文件头记载「英文定价页 2026-09-09 实测断供（服务端返回另一篇文档）」。本次调研经 curl 直连、exa、内置 WebFetch 三渠道确认英文页当前返回正确的定价内容（新版两列结构）。恢复 USD 抓取需为 `_PRICE_CELL_RE` 新增 `$X` 格式适配（现仅认「X元」），并更新文件头的局限说明。
- **fixture 需重新固化**：`tests/fixtures/deepseek_zh_2026-09-09.html` 是改版前三列快照（flash 旧价 0.10/3.0/9.0）。官网改版后应抓取新版页面替换快照并同步契约测试预期。

## 五、catalog 更新待决事项（供数据 PR 参考）

本次仅调研，不改动任何数据文件。更新 catalog 时需项目所有者确认的口径：

1. `flash` 条目 display 改为「V4.1-Flash」（CNY 数字与官网现价一致可不动，USD 更新为 peak $0.006/$0.3/$1.2，verified_at 与 revision 1→2）。
2. `vision` 条目转 `retired`（retired_at 2026-09-10）后，**保留价取哪个口径**：退役前的历史真实价（CNY peak 0.10/3.0/9.0、USD peak $0.014/$0.44/$1.32，字面符合「保留最后已知价」），还是旧名请求的实际扣费价（等于 flash 新价 0.04/2/8，catalog 当前存值）。两者不同，需定夺。
3. `pro` 条目：数字不变，但 09-14 12:00 起实际按 V4.1-Flash 价格计费直至 V4.1 Pro 上线；目录 schema 无「预告路由」字段，是否及如何在 UI/目录层呈现此过渡，需决策。
4. core 的 `provider/deepseek.rs` 只调用 `/user/balance` 查余额、未硬编码任何模型名（已核实），目录更新不牵动 core 代码。
