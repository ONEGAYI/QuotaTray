# 主度量与剩余口径端测清单（2026-09-26）

> **用途**：spec #137（主度量展示偏好与剩余口径统一）的真机验收——四消费面
> 口径一致性、低余额阈值迁移幂等与回滚、主度量偏好×窗口数据形态矩阵、
> 试查回退 toast、统计曲线双产。设计依据 [ADR 0020](<../adr/0020-主度量与剩余口径.md>)；
> Android 生效面分类见 [移动端能力缺口追踪.md](<../移动端能力缺口追踪.md>)
> 「真实设备验收」条目（2026-09-26 T-26 登记）。CLI 保持分列表格展示、
> 不受摘要位口径影响，不在本单范围。
>
> **测试机**：桌面为项目所有者 Windows 主机；Android 为所有者生活机
> （Android 16，实体 ARM64）。每项标注适用面：【两端】/【桌面】/【Android】——
> 托盘行体、托盘图标圆环与托盘悬停浮窗为桌面专属（Android 无托盘与
> 悬停窗口，模块为 no-op 替身）。
> **执行约定**：每项勾选 [x] 并附一行备注（异常现象/截图编号）；任一 Fail
> 项登记 issue 并在本单记录编号。
> **前置**：桌面与 Android 各安装携带 #137 的构建；至少一个百分比型条目
> （如智谱 GLM Coding Plan，多窗口 %）、一个金额型条目（如 DeepSeek /
> 阿里云百炼，仅 remaining）；建议另建一个**双料模板条目**（同一窗口同时
> 填 used/total 与 remaining，数据形状可控）用于矩阵项。

## A. 四消费面口径一致性（措辞翻转）

余额/限额条目在四个消费面的主文案全部为「剩余」族（`剩余 N%` /
`剩余 X 币`），与圆环（悬停浮窗圆环、托盘图标圆环，本就剩余口径）数字
方向一致；红色高亮/⚠ 的方向为**剩余 ≤ 阈值触发**。

- [ ] A1【两端】百分比型条目主页卡片：主数值「剩余 N%」（N = 100−已用），
      label「剩余额度」（多窗口为逐窗口行「剩余 {窗口}」，如「剩余 5h」）；
      不再出现「已用 N%」措辞
- [ ] A2【两端】金额型条目主页卡片：主数值「剩余 X CNY」，label
      「可用余额」（金额值本就是剩余绝对值，无方向可翻）
- [ ] A3【两端】卡片红色高亮时机：剩余百分比 ≤ 低余额阈值才出现；纯金额
      条目（算不出剩余百分比）永不触发高亮
- [ ] A4【桌面】托盘悬停浮窗：hero 主数值与卡片同口径（「剩余 N%」/
      「剩余 X 币」，label「剩余额度」）；圆环中心数字为剩余百分比且与
      主数值同度量；告警态圆环描红与卡片高亮同时机
- [ ] A5【桌面】托盘行体：百分比行「名称 · 剩余 58% · 3 分钟前」、
      金额行「名称 · 剩余 62.97 CNY · 3 分钟前」、多窗口行带窗口名
      （「名称 · five_hour 剩余 58% · …」）；剩余 ≤ 阈值的行首加「⚠ 」，
      未用尽额度不再出现 ⚠
- [ ] A6【两端】消息中心低余额卡片与系统通知正文：「{名称} 剩余 N%」；
      桌面通知在主窗不可见时弹（`notify_desktop`），Android 在后台
      （Worker 刷新或查询在途时退后台，`notify_background`）送达，
      通知开关关闭时两端均拦截
- [ ] A7【两端】数据不足回退：窗口既无百分比原材料也无 remaining 时
      显示「已获取」（桌面行体同措辞），不显示空白

## B. 低余额阈值迁移与回滚（升级路径）

存量设置字段改名迁移：旧键 `low_balance_threshold_percent`（已用 ≥ 触发）
→ 新键 `low_balance_remaining_percent`（剩余 ≤ 触发），加载时取
100−旧值写入新键并删旧键；触发时机数值等价（旧 80 已用 = 新 20 剩余）。
开发期桌面可用便携版/安装版手工构造 settings.json 快验
（`~/.quotatray/settings.json` 或 exe 旁 `Data/settings.json` 写入
`"low_balance_threshold_percent": 80` 后启动）；升级前后触发时机等价
与 Android 侧随**跨版本覆盖升级验收**（见 2026-08-29 安卓端测清单 B）执行。

- [ ] B1【桌面】旧键 80 启动：设置页「低额度提醒阈值（剩余 %）」显示 20；
      提示文案为「额度剩余低于该比例时显示提醒」
- [ ] B2【桌面】重复加载不翻转：保持旧键文件反复重启多次，值恒为 20
      （迁移是磁盘内容的纯函数，二次读不到新键不做二次翻转）
- [ ] B3【桌面】改设置持久化：阈值改 30 → 保存 → 重启仍为 30；
      settings.json 落盘新键 `low_balance_remaining_percent`、旧键消失
- [ ] B4【桌面】回滚安全：用升级前备份的 settings.json（旧键 80）回放
      → 仍迁移为 20 不交替翻转；新版保存后的文件（无旧键）交旧版本程序
      读取 → 旧程序读不到旧键走默认 80（已用）= 剩余 20，触发时机等价
      不颠倒
- [ ] B5【两端】恢复阈值组合校验：恢复阈值（默认 95）须严格高于低余额
      阈值，违反时保存被拒并提示「恢复阈值须高于低余额提醒阈值（均为
      剩余比例），请调整后保存」
- [ ] B6【两端】升级后触发时机等价：迁移完成的存量条目在剩余跌破 20%
      时首次触发低余额消息/高亮（与升级前已用越过 80% 的时点相同），
      持续达标静默、回落清除后再次达标重提

## C. 主度量偏好 × 窗口数据形态矩阵

条目级偏好三档（自动/百分比/金额）× 窗口形态。期望矩阵（卡片主文案，
悬停浮窗 hero 同口径）：

| 窗口形态 \ 偏好 | auto | percent | amount |
|---|---|---|---|
| 百分比型（仅百分比可算） | 剩余 N% | 剩余 N% | 回退：剩余 N% |
| 金额型（仅 remaining） | 剩余 X 币 | 回退：剩余 X 币 | 剩余 X 币 |
| 双料窗口（两者皆可算） | 剩余 N% | 剩余 N% | 剩余 X 币（金额优先） |

编辑对话框「主度量展示」三段控件位于控制台直达之后、峰谷定价之前；
保存后摘要位即时生效，重启与配置迁移包往返保持。

- [ ] C1【两端】按上表逐格验证双料条目（构造模板：同窗口填 used/total +
      remaining）与单形态条目在 auto/percent/amount 三档下的卡片主文案
      与 label（百分比档「剩余额度」族、金额档「可用余额」族）
- [ ] C2【桌面】amount 档悬停浮窗圆环变**余额环**：中心为剩余金额紧凑值、
      按每圈单位分层（设置「每圈单位」默认 100）；percent/auto 档维持
      百分比环；数据不支持时回退另一度量（文案与圆环同度量）
- [ ] C3【两端】混合多窗口逐窗口回退：多窗口条目（如智谱 5h/周 % 窗口
      + 金额窗口，或模板构造）设 amount 档——有 remaining 的窗口显示
      金额、无金额的窗口逐窗口回退显示「剩余 N%」，互不影响
- [ ] C4【两端】偏好持久化：保存偏好 → 重启应用 → 摘要位仍按该偏好渲染；
      配置导出 → 导入迁移包后偏好随条目走
- [ ] C5【两端】偏好不影响数据与告警：查询结果字段、历史曲线数值、低余额
      ⚠/高亮判定（恒为剩余百分比阈值）不随偏好变化
- [ ] C6【两端】auto 缺省行为零变化：未配置偏好的存量条目升级后摘要位
      仅措辞口径翻转（A 组），推断语义（百分比优先）不变

## D. 试查回退 toast（编辑对话框）

偏好与窗口数据形态不符导致的静默回退在试查反馈区点出：toast 右对齐、
带关闭按钮、不自动消失；`auto` 恒不警告。模板与脚本两种形态试查区都接入。

- [ ] D1【两端】percent 偏好 + 含无百分比原材料窗口的条目试查成功：
      toast 出现于试查反馈区（右对齐），文案「{窗口}无百分比数据，将按
      金额显示」列出全部回退窗口名（多窗口顿号分隔，无名窗口用序数
      「窗口 N」）；试查摘要中回退窗口按金额显示
- [ ] D2【两端】amount 偏好 + 无 remaining 窗口：文案「{窗口}无剩余金额，
      将按百分比显示」，摘要回退窗口按「剩余 N%」显示
- [ ] D3【两端】auto 偏好（含缺省）任何数据形态：无 toast
- [ ] D4【两端】不自动消失：toast 出现后停留 ≥1 分钟仍在（无自动隐藏
      定时器）；点「×」关闭后消失；再次试查成功按新回退清单重置
      （清单为空则不再出现）
- [ ] D5【两端】偏好控件与试查联动：三段控件切换（自动/百分比/金额）
      后再试查，摘要与 toast 按新偏好即时反映
- [ ] D6【Android】触摸实效：toast 关闭钮 44px 命中区可轻松点中
      （`qt-fallback-toast-close` 移动端直接加高）；三段控件命中正常
      （对应缺口追踪「真实设备验收」条目 T-23 登记）

## E. 曲线双产（统计页）

同一窗口派生「剩余百分比」与「金额」两条独立可选组合项；组合 id、候选、
scope 匹配与删除全链路带度量维度；4 条上限不放宽，同窗口双占计入上限。

- [ ] E1【两端】添加组合对话框：同窗口出现两个候选项，双度量同窗口时
      选项追加度量标注区分（「{窗口} · 百分比」/「{窗口} · 金额」）；
      % 单位窗口不出金额候选
- [ ] E2【两端】同窗口金额+百分比两条组合同时上曲线：并存互不挤占，
      图例按度量区分；百分比曲线恒剩余方向（数值 = 剩余百分比）
- [ ] E3【两端】4 条上限：选中 4 条（可含同窗口双占）后添加第 5 条被拒，
      提示「已达到 4 条上限；请先在『聚焦组合』中删除一个组合。」
- [ ] E4【两端】单位冲突隐藏：金额轨首单位定轨（如 CNY），异单位金额
      组合（如 USD）隐藏并提示「有 N 条组合因绝对值单位与 CNY 不兼容，
      暂未显示」；百分比轨恒无单位冲突
- [ ] E5【两端】存量兼容：升级前保存的无度量组合仍正常显示（按现有
      单选派生回填度量用于匹配，不主动落盘）；删除只删命中度量的那条，
      同窗口另一度量组合保留
- [ ] E6【两端】持久化：含同窗口双度量的组合选择保存后重启仍在；
      设置迁移包往返组合不丢失
- [ ] E7【Android】触摸实效：添加组合对话框、聚焦组合模态与图例的触摸
      操作正常（并入缺口追踪既有统计页真机验收项）
