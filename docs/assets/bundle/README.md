# docs/assets/bundle — 随应用打包的指引图片资产

配置指引文档（`docs/guide/*.md`）引用的图片统一放本目录。构建时由前端
`src/components/guideDocs.ts` 经 vite `import.meta.glob("…?url")` 收集并
复制进应用资产（哈希命名），文档内引用与打包产物名自动解耦。

## 引用约定

- 文档内写相对仓库 `docs/` 的路径：`![截图说明](assets/bundle/文件名.png)`
- 支持扩展名：`png` / `jpg` / `jpeg` / `svg` / `webp`
- 当前为空目录预留（2026-08-30 所有者定案：渲染器先具备图片能力，资产
  后续按需补充）；文件缺失时指引页渲染「图片缺失」占位，不阻塞文档

## 注意

- 只放指引文档实际引用的图片，不放无关素材（本目录内容会全部进包）
- 敏感信息（密钥、账号 ID、真实余额）入图前必须脱敏
