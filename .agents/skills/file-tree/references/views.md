# 视图与标记块：完整操作参考

file-tree 技能多视图能力的完整参考。SKILL.md 只保留命令速查与概述，本文档承载全部操作细节：命令行为、id 与行号规则、过滤器表达式、剪影投影、镜像与病态拦截、生命周期、check 诊断与渲染覆盖。术语（视图、默认视图、标记块、过滤器、剪影）与仓库根 CONTEXT.md 一致。

## 概念速览

- **视图（view）**：登记在 tree.json 顶层 `views` 键的渲染配置实体，由唯一 id、过滤器与绑定文档清单组成。视图不是第二棵树——它是同一份 tree.json 数据的切片投影（剪影），一个视图把同一份渲染内容镜像到它的全部绑定文档。
- **默认视图（default view）**：隐式视图，不带 id，固定渲染到 AGENTS.md 的树块与标签词表块；不出现在 `views` 配置中、不可删除。无 `views` 键的仓库只有默认视图，行为与历史版本完全一致。
- **标记块（block）**：绑定文档中由起止标记行界定、脚本渲染占位的区域，以视图 id 标识；代码围栏包裹，只含树块（无标签词表块）。块内内容是渲染产物，禁止手改，`check` 会当场暴露漂移。

## 命令全表

```bash
python .agents/skills/file-tree/scripts/tree_tool.py <命令>

# 登记视图（同 id 重复执行 = upsert：过滤器、渲染覆盖与绑定文档清单替换为本次参数）
view-add <id> (--under <目录>)... [--tag <标签>]... [--exclude <目录>]... [--filter <清单.json>]
              [--collapse <目录>|--expand <目录>|--hide <路径>|--show <路径>]... [--overrides <清单.json>]
              [--doc <路径> [--line N]]   # --doc 省略 = 仅落盘配置不渲染（既有绑定清单被清空，块保留为孤儿）
                                      # --line 须与 --doc 同用；行号语义见下文；覆盖参数语义见 render_overrides 节
# 既有视图的绑定文档增量调整（视图须已存在）
view-doc <id> (--add <路径> [--line N] | --rm <路径>)
                                      # --add 绑定新文档并渲染镜像块（重复绑定报错；孤儿块原地激活刷新；
                                      #   --line 仅作用于新文档，既有镜像原地刷新不重定位）
                                      # --rm 解绑并保留文档中的块（孤儿状态，不再刷新）

# 删除视图
view-rm <id> [--purge]                # 默认仅删配置，各绑定文档的块保留为孤儿；
                                      # --purge 按绑定清单逐一删除各文档中的块（删前校验每文档恰好一个，
                                      # 缺失/多个/文档不在磁盘即原子拒绝；只删标记行与块内内容，块外一字不动）

# 概览
view-list                             # 全部视图的 id / 过滤器摘要 / 绑定文档数 / 块存在情况
```

全部 view-* 命令都是数据变更：进 undo/redo 同一撤销栈（默认各留 20 步），单步历史；每次执行后自动渲染默认视图与全部视图。

## 视图 id 规则

- 语法：`[a-z0-9][a-z0-9_-]{0,63}`——小写字母或数字开头，仅小写字母/数字/连字符/下划线，总长 1–64，非法即报错拒绝。
- 保留字：`default` 是默认视图的保留字，不可登记。

## 标记块形态

每个视图的块由五行骨架构成：围栏开行、起始标记行、树形内容（多行）、结束标记行、围栏闭行。标记行**整行精确匹配**，形如（以 id `ext` 为例，此处行内展示）：

- 起始行：`<!-- file-tree:tree^id=ext:begin 由脚本渲染，禁止手改 -->`
- 结束行：`<!-- file-tree:tree^id=ext:end -->`

同一文档内同一 id 至多一个块；同一 id 在全部绑定文档中的块内容完全相同（同一渲染产物的镜像）。

## `--line` 行号语义

`--line N` 是"围栏首行落第 N 行"的承诺落点，用于把块放到文档指定小节而不是尾部：

- **1-based**，插在当前第 N 行内容之前（围栏开行最终落在第 N 行）。
- **越界报错拒绝**而非静默钳制：N 必须落在 1..文档总行数，否则命令报错且不落盘（写盘前 dry-run 校验，拒绝保持原子）。
- **上方空行保证**：原第 N-1 行非空时，插入序列自带一行前导空行（空行占第 N-1 行、围栏仍落第 N）；N=1（文档头）无上方约束。
- **下方空行保证**：块后首行非空则补一行空行，Markdown 段落结构不被破坏。
- **省略**：块已存在则原地更新内容，不存在则追加文档尾部（块外上方保证至少一行空行）。
- **重定位**：同 id 已有块且给定 `--line` 时，先删除旧块（含围栏与紧邻保障空行），行号以删除旧块后的文档为基准。

## 过滤器

过滤器是视图的范围定义：一棵表达式树，在 tree.json **全量条目**（含目录）上求值，返回选中路径集合。

### 五种节点

| 节点 | 形态 | 语义 |
| --- | --- | --- |
| `under` | `{"op": "under", "path": "apps"}` | 目录锚点的前缀子树，**锚点自身含入**；锚点必须是树中已存在的目录条目 |
| `tag` | `{"op": "tag", "tag": "doc"}` | 带该受控标签的全部条目；标签必须已在词表登记 |
| `not` | `{"op": "not", "child": {…}}` | 全量条目上的补集（非仅选中集内取反） |
| `and` | `{"op": "and", "children": […]}` | 子节点求值的交集；children 为非空数组 |
| `or` | `{"op": "or", "children": […]}` | 子节点求值的并集；children 为非空数组 |

节点只允许 `op` 与各自参数字段（`path`/`tag`/`children`/`child`），未知字段拒绝；`under` 路径统一归一为正斜杠形式落盘。

### 快捷参数的编译规则

`view-add` 的 `--under` / `--tag` / `--exclude` 快捷参数编译为规范表达式树落盘：

- 多锚点为**并集**（`or` 包裹多个 `under`，单锚点退化为裸 `under` 节点）
- 锚点 × 标签为**交集**（`and` 连接；多标签同为交集）
- `--exclude` 为**差集**（每个排除锚点包成 `not(under)` 挂入 `and`）
- 三个维度都在时整体为 `and`，children 依次为锚点组 → 标签 → 排除；各组内按确定性排序去重
- 快捷参数与 `--filter` 清单**互斥**；纯 `--exclude`（无 `--under`/`--tag`）无被减对象，拒绝

### `--filter` 清单（完整布尔组合）

超出快捷参数表达力的组合（`not`、任意嵌套）走清单文件，顶层形如：

```json
{"filter": {"op": "and", "children": [
  {"op": "under", "path": "apps"},
  {"op": "not", "child": {"op": "tag", "tag": "internal"}}
]}}
```

清单与 add-batch 同风格：原样 JSON 读入，交由 view-add 校验并收敛为规范表达式树。

### 引用预检与空选中

- **引用预检在写盘前**：`under` 引用必须是树中已存在的目录条目、`tag` 引用必须已登记——不满足即拒绝，不落盘、不留撤销历史。过滤器错误在源头拦截。
- **选中 0 条告警放行**：view-add 打印警告并正常创建（空视图渲染仅剩根名行），check 同样告警——用于识别"过滤器过窄"而非静默接受。
- 数据操作（`rm`/`mv` 等）不经过预检：过滤器锚点被删后悬空是合法中间态，渲染层跳过该视图并告警，check 降为告警诊断（见下文），修正手段是重建或改过滤器。

## 剪影投影规则

过滤器选中集投回全树结构，收敛为一棵可读的局部树：

- **首行是全局 root 名**（与默认简版树同源，非子目录名）。
- **选中条目正常渲染**：简介（desc）照常显示；选中目录的 `collapsed` 折叠生效。
- **未选中祖先目录作路径骨架**：仅保留"含有选中后代"的祖先，只作容器——不显示简介、忽略 `collapsed` 强制展开（折叠会丢内容）。
- **hidden 条目在任何视图不出现**：hidden 目录连同整个子树跳过，与默认简版树同语义；数据层隐藏语义全局一致。
- **不连通的选中集**（散文件与多目录混合）按同一投影规则收敛为一棵树。
- **空选中集**渲染仅剩根名行一行。

## 多文档镜像与病态拦截

一个视图 id 可绑定一个或多个文档（`view-doc --add` 增量扩充）。镜像规则：全部绑定文档中的块内容**完全相同**，任何数据变更后全部镜像同步刷新；绑定文档在磁盘上缺失时跳过该文档（不凭空创建），其余照常。

**同一文档内同 id 出现多于一个块属病态**：view-add、view-doc 及触发渲染的数据命令都会报错，指明文档路径与块数，不做猜测性修复——手改删除多余块后重跑 `render` 即可恢复。渲染计划在落盘前 dry-run（行号越界、孤立标记、多块都在拒绝时暴露），命令保持原子。

## 生命周期与撤销

| 动作 | 配置（views 键） | 文档中的块 |
| --- | --- | --- |
| `view-add`（新 id） | 登记实体 | 渲染/插入到绑定文档 |
| `view-add`（同 id upsert） | 过滤器与绑定清单**替换为本次参数** | 不带 `--doc` 时既有绑定被清空，各文档块保留为孤儿 |
| `view-doc --add` | 清单追加 | 新文档渲染镜像块（孤儿块原地激活刷新） |
| `view-doc --rm` | 清单移除 | **保留**（孤儿状态，不再刷新），剩余镜像照常刷新 |
| `view-rm` | 删除实体（views 空则整键不落盘） | **保留**为孤儿 |
| `view-rm --purge` | 删除实体 | 按绑定清单逐一删除（删前校验每文档恰好一个，原子拒绝；拼接点不产生双空行粘连） |

孤儿块是合法状态：不再被任何渲染刷新，check 以告警提示（见下文）。清理孤儿块用 `view-add` 同 id 重建后 `view-rm --purge`，或手改删除。

全部 view-* 命令为单步撤销历史；块插入位置无法由数据纯函数重推导，撤销快照包含受影响文档全文——undo/redo 连同配置与块渲染产物（含位置）一并恢复。

## check 两级诊断

`check` 对视图做两级诊断，`--strict` 下告警同样视为失败：

**错误级**（绑定文档与配置的一致性）：

- 绑定文档不存在（恢复文档，或 view-add 重建绑定清单移除悬空绑定）
- 同 id 多块（手改删除多余块后重跑 render）
- 缺块 / 缺开始或结束标记（重跑 view-add 或任一数据命令可纠正）
- 块内容与渲染产物漂移（产物过期或被手改，重跑 render）
- render_overrides 覆盖引用不在树中、collapsed 指向文件条目（rm 后的悬空是合法中间态来源；重建路径或移除覆盖项）

**告警级**：

- 全仓库 `.md` 扫描带 id 的标记行，命中**未登记 id** 即报孤儿块（多为手写笔误或 view-rm 保留产物），给出文件与行号
- 不可渲染视图（过滤器 `under` 引用悬空等）降为告警并跳过该视图的块内容比对，与渲染期两级一致
- 过滤器**选中 0 条**（过滤器过窄或数据变更后失去全部条目）：告警识别而非静默接受，空视图渲染仅剩根名行（与 view-add 落盘时同一告警口径）

孤儿扫描的豁免边界：技能目录自身文档、代码围栏内的示意行；但**块自身的包裹围栏不算豁免围栏**——围栏开行紧跟标记行的"完整块形态"与真块在文本层不可区分，按真块报告。

## render_overrides（视图级渲染覆盖）

`render_overrides` 是 per-view 可选键，按路径索引改写该视图内条目的 `hidden`/`collapsed` 有效值：

- 形态：`{"路径": {"collapsed": bool, "hidden": bool}}`；空覆盖项 `{}` 报错（无字段即无语义的手改信号），整体空对象时省略键
- 优先级：**视图覆盖 > 条目全局字段 > 默认值**；布尔双向——`hidden: false` 反向显示全局隐藏条目、`collapsed: false` 反向展开全局折叠目录；`false` 是语义值保留落盘（区别于全局字段的 false 不落盘）
- 覆盖只影响渲染可见性：不改求值集合（选中集在全量数据上求值，hidden 不参与过滤）、不改条目全局字段、不影响其他视图与默认视图（AGENTS.md）
- `hidden` 为祖先优先剪枝（祖先有效 hidden=true 即整棵子树跳过，其后代覆盖不再查询，与全局 hidden 同语义）；骨架目录的 `collapsed` 覆盖被忽略（强制展开不破例，折叠会丢选中后代）；覆盖路径不在选中集与骨架中时不产生效果（覆盖不扩大渲染范围）
- 入口：`view-add` 快捷参数 `--collapse/--expand`（目录）、`--hide/--show`（文件或目录，可重复给多条，同路径同字段冲突拒绝、不同字段合并）编译落盘；多覆盖项走 `--overrides` 清单（`{"overrides": {...}}`，与快捷参数互斥）；upsert 整体替换覆盖配置，不给参数即移除键
- 写盘预检：覆盖路径必须在树中、`collapsed` 必须指向目录条目，拒绝保持原子；rm 后悬空是合法中间态——渲染静默忽略该项、`check` 报错、不阻塞数据操作

## 部署与兼容

- 本文档随部署固定清单进入每个目标仓库（技能目录 `references/views.md`）。
- 旧版工具对 `views` 键无感知且不破坏：tree.json 升级部署的永不触碰清单已覆盖它，新旧版本混布互不损坏。
- GUI 查看器（viewer.py）只读 root/tags/tree 三键，含 `views` 键的快照正常加载浏览。
