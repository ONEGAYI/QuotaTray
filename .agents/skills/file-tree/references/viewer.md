# 只读查看器使用参考

此文档供使用或排查 `viewer.py` 时按需阅读。文件树增删改仍通过 `tree_tool.py`；查看器只读取指定的 `tree.json` 快照。

## 启动与刷新

```bash
python .agents/skills/file-tree/scripts/viewer.py <tree.json 路径> [--port N] [--host H]
```

- 运行需要 Python 3.8+ 与现代浏览器，无需 Node。页面发行资源随技能部署在 `viewer/`。启动后打印访问地址，默认 `http://127.0.0.1:8618/`；按 Ctrl+C 停止。
- 默认仅监听本机。远端浏览时可自行建立 SSH 隧道：`ssh -L 8618:127.0.0.1:8618 user@server`，再在工作站浏览器访问默认地址。
- 快照可位于仓库之外，例如从旧机复制来的 JSON；查看器不需要源仓库、`.git` 或 AGENTS.md。复制 JSON 本身不需要 Python，运行查看器才需要。
- 浏览、搜索、刷新不写数据、不转换格式、不生成撤销历史。替换同一路径的 `tree.json` 后，在页面点**刷新**即可重读，不必重启或重新构建。

## 界面操作

- 普通侧栏默认 310px，可拖动宽度，或用分隔条左右键每次调整 10px；范围为 240px 至 `min(440px, 0.46W)`，其中 W 为正文扣除 9px 分隔条后的可用宽度。缩小窗口仅钳制当前显示宽度，放大后恢复。
- **层级浏览**将侧栏扩至 80%，显示按需加载的目录列；此模式停用分隔条。使用**收起层级**或**收起并阅读全文**恢复普通宽度与当前选择。窗口宽度不超过 600px 时上下排列，仍可切换布局。
- 根面包屑可进入根概览和路径历史；复制文件时得到快照相对路径。布局切换保留搜索草稿及结果页，命中定位后可用**返回搜索**恢复原页；刷新按原条件重新查询第一页。
- 帮助面板列出树、层级列、分隔条和历史快捷键。布局偏好只存当前会话；原始标志默认折叠，三态信息仍可展开查看。

## 排错与验证

- Python 低于 3.8 时拒绝启动并打印当前及所需版本；快照不存在或路径是目录时给出错误。静态资源缺失时打印构建方法，页面返回 503，但 API 仍可用。3.8 是启动门槛，不等于该版本已经实测；已实测 Python 3.14.0 与 Windows Python 3.13.9。
- 查看器契约测试：`python .agents/skills/file-tree/scripts/viewer_test.py`。大样本生成与服务端性能基准仅用于构建或实测：`scripts/gen_viewer_sample.py`、`scripts/bench_viewer.py`。
