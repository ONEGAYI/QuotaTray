# 托盘图标规范

## T-015 细环与大数字（B 方案）

- **状态**：生效（2026-09-10，所有者已完成 B 方案实机验收并确认通过）。
- **归属**：`src-tauri/src/ring.rs` 与 `src-tauri/src/tray.rs`；本条是托盘图标样式的唯一规范，`docs/design/tray-ring-demo.html` 为演示页。
- **布局**：圆环宽度约占边长的 1/16，最小 1px；中心使用嵌入的粗体数字字形，按实际画布尺寸与文本长度等比排版。两位数字在 32px 画布上至少 14px 高；文字与圆环之间保留透明间隙。
- **文字**：百分比型图标只写 0–100 的整数，省略 `%`；悬停面板及菜单保留完整单位。余额从千位起用 k/M/B 缩写，例如 `3800 → 3.8k`，不更改业务数据。
- **尺寸**：Windows 按托盘所在屏幕的缩放比例选择像素尺寸，直接在目标画布绘制。托盘尚未建立或定位不可用时回退主屏；其他桌面平台保留 32px 默认。重建时重新读取缩放信息。
- **颜色**：保留既有单层阈值渐变、多层循环色、溢出青色、明暗文字和槽色。原生托盘由 Rust 直接生成 RGBA，不经过 WebView 的 CSS 令牌。
- **告警与无数据**：无可用数据保持灰色空环，不显示 0；低额度红点保留右上角位置，并在文字之后绘制。
- **验收**：使用真实 Rust 渲染器检查 16/20/24/32px，覆盖 0、38、88、100、3.8k、长缩写、明暗背景与告警；原尺寸检查优先，放大图仅用于观察像素。
