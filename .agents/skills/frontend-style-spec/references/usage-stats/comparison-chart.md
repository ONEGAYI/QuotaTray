# 使用统计多曲线比较

> 适用范围：`UsageStatsPage`、`UsageComparisonDialog` 与 `qt-usage-*` 样式。
> 颜色、圆角和时长引用 design-tokens 域；索引见 [SKILL.md](../../SKILL.md)。

## T-013 多曲线比较与组合浮窗

**组合契约**（2026-08-30 所有者确认；2026-09-16 修订删除入口与移动端形态）：最多四条
`Provider + 模型/额度窗口`组合；独立管理页已移除，删除收进桌面聚焦浮层与移动端
聚焦模态窗的行内两段确认，添加弹窗仅负责新增。组合、顺序与色槽落 `settings.json`，
颜色按固定色槽保持稳定；百分比可与一种绝对单位同图，第二种绝对单位不可添加。

**桌面聚焦触发器外形**（2026-09-16 所有者按手绘剖面确认）：沿用 secondary
按钮，外轮廓为完整药丸 A；右侧状态平台 B 下沉，左缘为向右凹入的月牙弧，右缘
为凸圆弧。A 顶面连续保留 B 上下及右侧窄沿；交界用窄暗边与底部亮边呈现垂直
台阶，不作斜坡或凸起芯片。B 底色为 accent 20% 与 surface 混合的淡紫色，保证
明暗主题下均能区分月牙交界（2026-09-16 所有者反馈）；井壁仍引用 shadow 与 border
系令牌，图示黄色仅用于区分区域。B 上行 `FOCUSING`、下行组合名及曲线色数值（空态为无聚焦组合），
底色用独立 `background-color` 声明；渐变半径避免 calc 混算（曾致整条 background
简写解析失败），避免浏览器拒绝渐变而连带丢失底色。背景遮罩不得裁文字；组合名过长省略，数值不压缩。整钮为聚焦入口，
全平台点击开合（2026-09-16 所有者裁决：悬停展开不保留，键盘 Enter/Space 经原生
click 同路径），保留全局键盘焦点环；桌面浮层经点击浮层外部（document mousedown
outside-tap）或 Esc 关闭。
关键取值：按钮最小高 42px、内边距上/右/下 4px 与左 14px；平台最小高 32px、
宽 132–240px、左凹弧深 18px、文字左内边距 27px 与右 14px；两行间距 2px，
上行 7px 与下行 11px。代码锚点为 `.qt-btn.qt-usage-legend-trigger`、
`.qt-usage-focus-platform::before`（仅裁装饰背景，凹弧深度不随平台宽度拉伸）。

**图表契约**：桌面悬浮详情按同一时间桶列出曲线；聚焦时只列聚焦项，清除聚焦
恢复全量。气泡横向跟随光标、纵向吸附到光标相反半区。短缺失用低透明连接，长缺失
直接断线且不生成插值；全量比较时不覆盖灰区，聚焦单条曲线时仅在该曲线的长期缺失
区间恢复灰色斜纹提示。移动端使用全宽响应式图表，单指拖动更新时间游标，读数常驻
图表下方；聚焦过滤与桌面一致。单个真实历史点以端点圆显示，不因无法生成 path 而
隐藏；迁移导入带来第二种绝对单位时保留组合，并在图表上方明确提示未显示数量。
曲线路径仅在展示桶不大于 15 分钟时采用半径 2 个桶的轻度局部高斯平滑
（2026-09-02 所有者确认）；超过 15 分钟的粗粒度桶（当前为 7 天档的 1 小时桶）
保持逐点单调曲线，避免真实平台被平均成三角波。平滑连续段的端点保持真实坐标；
样本值正向增加且纵向跳幅达到 `max(12 SVG 单位, 当前连续段纵向跨度 × 25%)` 时按
额度重置分段，段间以真实点直连，不跨重置做平滑。平滑只作用于视觉路径；桌面悬浮
读数、移动端常驻读数与交互圆点仍使用原始样本值。

**色槽契约**：图表与添加预览统一引用 DT-001 的 `--qt-series-1..4`，
不得在 TypeScript 中重复硬编码色值。

**定位线契约**（2026-09-05 所有者确认；2026-09-16 修订按钮三态与清空入口）：
图表卡头「定位线」按钮三态——放置模式中点击退出且保留；未满两条点击进入放置
直接补位；满两条再点清空两条并从头定位。放置模式中点击绘图区放置竖直定位线，
最多 2 条（纯函数超限丢最旧分支保留为防御，正常交互不可达）；放置与拖动吸附最近
真实样本时刻（容差 = 当前范围桶宽，吸附候选限定当前视图内——吸附到视图外
样本的线会被渲染过滤而不显示），重复时刻幂等忽略。每条线顶端手柄可沿
时间轴拖动微调（透明命中圆保证触达 ≥44px：移动端 r=22、桌面 r=18 SVG 单位；
拖动仅本地更新，松手一次性落盘，写盘失败回退已存值），
与另一条重合时原地不动。时刻与两线时间差常显在卡头下方读数行（跨端一致，
删除按钮逐条移除）；时间差分钟粒度向下取整且至少 1 分钟。读数行常驻并按满载
内容预留高度（桌面单行 / 移动端窄屏满载多行，2026-09-05 验收反馈），空态显示
引导文案，放置/删除/聚焦切换不得引起卡片高度跳变。一键清空入口为图表卡头
垃圾桶按钮（位于「定位线」与「重置视图」之间，仅清除不进入放置，无定位线时
禁用；2026-09-16 自读数行右端移入卡头），读数行内逐条 × 删除保留。
定位线关键取值登记（tokens.md 尾节规则）：读数行 11px 字号、预留高桌面 92px /
移动端 112px（2026-09-26 #135 净消耗加入后复核：桌面满载三行 22×3+4×2+17=91
取 92；移动端按五文本行预算 112）、定位线宽 1.4 SVG 单位、删除钮 22px 视觉（移动端叠
`qt-touch-inline` 外扩热区；一键清空为卡头 `qt-btn` 形态）。视外时刻在读数行以 55% 透明度弱化并带悬停说明。
聚焦单条曲线时每条定位线旁
按最近样本显示该曲线值（与悬浮读数同口径：原始样本值、容差同展示桶，无样本
显示「—」，值着曲线色槽色）；两条线齐备且聚焦时，时间差段内先追加净消耗、
再追加平均消耗速率与峰值消耗。曲线值方向显式化（2026-09-26 #135）：
`HistorySeries.quantity` 区分剩余量/已用量（百分比恒为剩余量；仅配 used 的
模板为已用量），平均/峰值速率与净消耗统一按「剩余量下降 / 已用量上升 =
消耗」换算——历史上速率按剩余量方向未对已用量补偿（方向反了），#135 同票
修正并补回归测试。净消耗是两条定位线对应原始样本的端点净变化（单位沿聚焦
曲线，负数表示区间净恢复；「净消耗」而非「总消耗」，避免把净值误认作累计
毛消耗）。悬停净消耗（桌面 span，tabIndex 可达 + focus/blur）或点击（Android
行内文字钮）展开分解：已观测累计消耗 / 已观测累计恢复 / 带符号未观测净
变化三行数值 + 代数说明小字，保证「已观测消耗 − 已观测恢复 + 未观测净变化
= 端点净消耗」；连续可观察的边界与 `splitUsageSeries` 的 segments 一致
（相邻样本桶距 ≤2 即视觉实线段），虚线桥与断档期间的变化不伪称已知，只
计入未观测净值；视觉平滑曲线不参与计算。桌面分解为从锚点向上弹的富内容
卡片（`qt-usage-marker-net-detail.is-popover`，富卡片豁免同 `qt-usage-tooltip`
先例），悬停宽限收起复用聚焦浮层控制器（240ms）、Esc 分层最先收；Android
为点击 disclosure（`aria-expanded`/`aria-controls`，展开块独占读数行一行，
`qt-touch-inline` 外扩热区），不依赖悬停。平均消耗速率为端点消耗方向变化量 ÷
marker 时间差小时数（值同聚焦取值口径；百分比曲线 `%/h`、余额曲线 `单位/h`
（单位为空时仅 `/h`），最多 2 位小数去尾零，负值表示区间回升）；净消耗与
速率共用 2 位小数去尾零格式（`-0` 归零；未观测净变化非零恒带显式符号）。
任一线无样本不显示；时间差不足 1 分钟无测量意义不显示，与时间差文案
「至少 1 分钟」口径对齐；速率与时间差共享同一换行段而非独立 flex 项，
2026-09-06 所有者确认），同为 650 字重主读数。速率段静态复核：桌面 minWidth
560 最窄窗口下聚焦满载本已接近单行上限，速率段使满载宽度再增约 100px，
默认宽度 780 单行可容纳，最窄窗口的实际换行行为列入人工验收；净消耗段
（含 14px 左距）再增约 90–110px，默认宽度下满载常态三行（2026-09-26 复核），
最窄窗口换行行为同样列入人工验收。定位线持久化在
`settings.json`（`usage_marker_lines`，仅本机，不进配置迁移包）；超出当前视图
不画线但读数保留。放置模式下桌面平移让位、悬浮十字线保留，Esc 或再点按钮
退出，放满两条自动退出。线与手柄色引用 DT-001 的 `--qt-chart-marker`，
不得与其他图表令牌混用。

**Android 组合浮窗特例**（2026-08-30 所有者确认）：本弹窗不沿用 T-011 的
设置/编辑全屏页，改为视口居中浮窗；宽度为视口减 20px，高度
`min(82dvh, 680px)`，xl 圆角、强边框、面板阴影。遮罩使用 text 28% 混色与
10px 背景模糊；点击遮罩、关闭钮、Esc 或 Android 返回键只关闭该浮窗。浮窗内部
点击不关闭；按钮与下拉命中区至少 44px。

**移动端聚焦模态窗**（2026-09-16 所有者确认）：药丸入口全平台统一渲染（有组合
即显示），移动端点击药丸打开聚焦组合模态窗，替代已退役的横向 chips。行列表与
桌面浮层同一套组件样式；移动端覆盖移动默认全屏弹窗策略，按组合浮窗特例同口径
恢复居中卡片、宽度视口减 20px、高度随内容自适应（最多四行，遮罩同
`qt-usage-dialog-backdrop`）。行触摸目标 44px，行尾删除钮同步放大命中（视觉
随之放大，T-010 图标钮口径），两段确认删除；关闭走 DialogShell 既有机制
（返回键/Esc/关闭钮/点击遮罩，返回键关闭为所有者裁决）。

**工具栏窄屏两行收拢**（2026-09-17 所有者反馈）：窄屏下组合工具栏不沿用 620px
媒体查询的列排三行（添加/药丸/时间尺度各占一行占高），改为添加组合+时间尺度
同行（`space-between` 靠右）、聚焦药丸次行；`comparison-actions` 以
`display: contents` 把三控件上交工具栏统一 wrap 排版，`order` 定序为添加→
时间尺度→药丸。药丸次行是宽度不足时的 wrap 涌现结果：宽视口（平板/折叠屏
展开）三控件同行 space-between 排开，垂直更省；无组合时添加与时间尺度
单行排布。

**卡头窄屏换行**（2026-09-19 真机回归修复）：图表卡头移动端覆盖为
`flex-flow: row wrap`（行距 8px 对齐工具栏 wrap 先例，列距维持基类 20px）：
宽视口标题与按钮组同行 `space-between`，放不下时按钮组自然换到次行。回归
背景：不换行的 row 覆盖在卡头挂「定位线 + 垃圾桶 + 重置」三钮并加 44px 热区后
同行放不下，标题块被 flex 收缩至 min-content，CJK 逐字断行成竖排（真机截屏
确认）；桌面窄窗走 620px 媒体查询的 column 回退不受影响。mobile-style 契约
测试锁定 wrap 形态并禁止回归无 wrap 的整流覆盖。
